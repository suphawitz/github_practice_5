# Team Rules

Workshop นี้ทำงานร่วมกันทั้งทีมประมาณ 7–8 คน

ทีมต้องวางแผนและแบ่งงานกันเองก่อนเริ่มพัฒนา

### กติกาการทำงาน

- สมาชิกทุกคนต้องมีส่วนร่วมใน Project
- สมาชิกแต่ละคนต้องทำงานบน **Feature Branch ของตัวเอง**
- ห้ามพัฒนา Feature โดยตรงบน `main`
- สมาชิกทุกคนต้องมี Commit ของตัวเอง
- สมาชิกทุกคนต้องเปิด Pull Request อย่างน้อย 1 PR
- ทุก PR ต้องมี Reviewer ที่เป็นสมาชิกคนอื่นในทีม
- ห้าม Review PR ของตัวเอง
- สมาชิกทุกคนต้อง Review งานของเพื่อนอย่างน้อย 1 PR
- Reviewer ต้องตรวจ `Files changed` และให้ Feedback ตามความเหมาะสม
- หาก Reviewer ขอแก้ไข ให้เจ้าของ PR แก้และ Push กลับเข้า Branch เดิม
- PR ต้องผ่าน Review ก่อน Merge เข้า `main`
- หลังมีการ Merge งาน สมาชิกควร Sync `main` ล่าสุดก่อนเริ่มงานส่วนถัดไป
- เมื่อจบ Workshop งานทั้งหมดต้องอยู่ใน `main`

## สิ่งที่อาจารย์จะตรวจ

- เว็บไซต์ครบทั้ง 3 หน้า
- ความใกล้เคียงกับ Design Reference
- Navigation ใช้งานได้จริง
- Layout และ Style สอดคล้องกันทั้งเว็บไซต์
- Code อ่านและจัดโครงสร้างได้เหมาะสม
- สมาชิกทุกคนมีส่วนร่วม
- Branch และ Commit History
- Pull Requests (ทุกคนในทีมต้องเปิด PR อย่างน้อย 1 ครั้ง)
- Code Review (ทุกคนในทีมต้องได้เป็นคน Review อย่างน้อย 1 ครั้ง)
- การแก้ไขงานจาก Review
- การ Merge เข้า `main`
- Final Project สามารถเปิดใช้งานได้ครบถ้วน
